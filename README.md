
# 🏋️ Fitness Website

A modern and responsive **Gym and Fitness Website** built using HTML, CSS, and JavaScript. This project helps users explore workout plans, fitness programs, membership plans, and health tips.

## 🌟 Features

- 🏋️ Workout Plans
- 💪 Fitness Programs
- 💳 Membership Plans
- 🥗 Health Tips
- 📱 Responsive Design
- 🎨 Premium Black-and-Red Theme
- 📩 Interactive Form with JavaScript Popup Messages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
FITNESS-WEBSITE/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/priyanshibhardwaj07082008-glitch/FITNESS-WEBSITE.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
